 Akko 3108 V2 OpenRGB Plugin - Windows x64 (MSVC, Qt6)
====================================================================

CONTENUTO
---------
  AkkoKeyboardPlugin.dll      Plugin OpenRGB (Plugin API v5, x64)
  INSTALL-WINDOWS.txt         Questo file
  LICENSE                     GPL-2.0-or-later
  (il plugin NON richiede DLL esterne per hidapi: e' incluso
   staticamente nel plugin)

REQUISITI
---------
  - OpenRGB 1.0 per Windows compilato con MSVC + Qt6.
    Molto importante: la .dll del plugin deve avere lo STESSO
    compilatore (MSVC) e la STESSA major di Qt dell'OpenRGB che la
    carica. Un plugin compilato con MinGW/GCC NON viene caricato da
    un OpenRGB MSVC (e viceversa).
  - Se il tuo OpenRGB Windows usa Qt5, serve una build Qt5 del
    plugin (compilala dai sorgenti con -DOPENRGB_PLUGIN_QT6=OFF).

INSTALLAZIONE
-------------
  1. Apri la cartella di configurazione di OpenRGB:
       Win+R  ->  %APPDATA%\OpenRGB
  2. Crea la cartella "plugins" se non esiste:
       %APPDATA%\OpenRGB\plugins
  3. Copia AkkoKeyboardPlugin.dll dentro %APPDATA%\OpenRGB\plugins\

POI
---
  1. Riavvia OpenRGB
  2. Impostazioni -> Plugin -> spunta "Attivato"
  3. La tab "Akko Editor" e il device "Akko 3108 V2" in Device page.

NOTE
----
  - Backup: se esiste una versione precedente della dll, rinominala
    manualmente (es. AkkoKeyboardPlugin.dll.bak) prima di copiare la
    nuova.
  - Questa build e' prodotta in automatico da GitHub Actions ed e'
    da considerarsi "beta" finche' non viene testata su un Windows
    reale con l'OpenRGB di destinazione.
