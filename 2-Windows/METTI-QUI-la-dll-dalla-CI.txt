 2-Windows/ — come ottenere la .dll (spiegazione)
====================================================================

La AkkoKeyboardPlugin.dll NON si puo' compilare su CachyOS/Arch
perche' serve Visual Studio (MSVC) + Qt per Windows: il formato e'
diverso (.dll e non .so) e l'ABI deve combaciare con l'OpenRGB
Windows ufficiale (MSVC, non MinGW).

Per ottenerla ci sono DUE strade:

--------------------------------------------------------------------------
 STRADA A (consigliata, automatica): la crea la CI dalla GitHub Release
--------------------------------------------------------------------------
  1. Pubblichi i sorgenti su GitHub (vedi PUBBLICARE.md) e fai il
     tag "v*" (es. v1.0.0).
  2. Il workflow "Release builds" compila da solo la .dll su
     windows-2022 (MSVC + Qt6) e la allega alla Release dentro
     Akko-OpenRGB-Plugin-windows-x64.zip.
  3. Non devi fare NULLA a mano: scarichi lo ZIP dalla Release.

--------------------------------------------------------------------------
 STRADA B (manuale): la scarichi dai "Artifacts" del workflow
--------------------------------------------------------------------------
  Se vuoi la dll subito, SENZA creare una Release:
  1. GitHub -> tab Actions -> workflow "Release builds"
  2. "Run workflow" (puoi lanciarlo senza tag)
  3. Quando finisce, in fondo alla pagina trovi "Artifacts":
     scarica Akko-OpenRGB-Plugin-windows-x64
  4. Estrai AkkoKeyboardPlugin.dll e copiala QUI nella cartella
     2-Windows/
  5. Poi ri-zippa la cartella (deve contenere la dll + il file
     INSTALL-WINDOWS.txt + LICENSE) in:
     Akko-OpenRGB-Plugin-windows-x64.zip

NOTA IMPORTANTE
---------------
  La dll prodotta dalla CI e' da considerarsi BETA: nessuno l'ha
  ancora provata su un Windows reale. Prima di pubblicarla come
  stabile, fai testare a qualcuno con Windows:
   - copia la dll in  %APPDATA%\OpenRGB\plugins\
   - apri OpenRGB -> Impostazioni -> Plugin -> Attivato
   - deve comparire la tab "Akko Editor" e il device "Akko 3108 V2"
